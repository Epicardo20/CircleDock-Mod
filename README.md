# CircleDock-Mod

Circle Dock program for remote desktop access to the applications they use, but with a pop-up stating that a password is required to delete the icon.

## Características principales
* Acceso directo a aplicaciones de escritorio remoto.
* Protección mediante contraseña para evitar la eliminación accidental o no autorizada de los iconos.

## Descarga e Instalación

Para utilizar el programa, no es necesario descargar todo el código fuente. 

1. Ve a la sección de **Releases** en la barra lateral derecha.
2. Descarga el archivo `.zip` de la última versión.
3. Descomprime el archivo en tu computadora y ejecuta la aplicación.
